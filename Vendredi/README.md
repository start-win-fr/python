# Vendredi : algorithmes classiques et code propre

Les corrigés commentés des exercices du vendredi. Chaque fichier se lance avec `python3 nom_du_fichier.py`.

| Fichier | Exercice |
|---|---|
| `v1_devine.py` | V1. Le juste prix, c'est l'ordinateur qui devine |
| `v2_bulles.py` | V2. Le tri à bulles, avec le nombre d'échanges |
| `v3_puissance.py` | V3. La puissance, en récursif |
| `v4_chiffres.py` | V4. La somme des chiffres, en récursif |
| `v5_palindrome.py` | V5. Le palindrome, en récursif |
| `outils.py` et `menu.py` | V6. Une boîte à outils dans un module, et un programme qui l'importe |
| `v7_plus_long.py` | V7. La chasse au bug, version corrigée |
| `v8_hanoi.py` | V8. Les tours de Hanoï |
| `v9_fusion.py` | V9. La fusion de deux listes triées |

Pour V6, lancez `python3 outils.py` (les tests s'affichent), puis `python3 menu.py` (les tests ne s'affichent plus) : c'est tout l'effet de `if __name__ == "__main__":`.
