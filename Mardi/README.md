# Mardi : boucles, listes, chaînes, fonctions

Les corrigés commentés des exercices du mardi. Chaque fichier se lance avec `python3 nom_du_fichier.py`.

| Fichier | Exercice |
|---|---|
| `m1_table.py` | M1. La table de multiplication, puis toutes les tables |
| `m2_rebours.py` | M2. Le compte à rebours, avec `while` puis avec `for` |
| `m3_somme.py` | M3. La somme de 1 à n, vérifiée avec la formule de Gauss |
| `m4_stats.py` | M4. Les statistiques d'une classe, sans `sum`, `min` ni `max` |
| `m5_voyelles.py` | M5. Compter les voyelles |
| `m6_palindrome.py` | M6. Le palindrome, en trois versions |
| `m7_fizzbuzz.py` | M7. FizzBuzz |
| `m8_indice.py` | M8. La recherche dans une liste |
| `m9_premiers.py` | M9. Les nombres premiers inférieurs à 100 |
| `m10_notes.py` | M10. La saisie des notes jusqu'à « fin » |

Essayez d'abord seuls. Le corrigé sert à comparer, pas à recopier.
