# Mercredi : corrigé du TP « trois petits jeux »

Une version par étape, telle qu'elle doit fonctionner à la fin de l'étape, puis une version complète avec les bonus. Chaque fichier se lance avec `python3 nom_du_fichier.py`.

| Jeu | Étapes | Version complète |
|---|---|---|
| Le nombre mystère | `mystere_etape1.py` à `mystere_etape5.py` | `mystere_complet.py` : niveaux, coups hors limites, rejouer |
| Le calcul mental | `calcul_etape1.py` à `calcul_etape4.py` | `calcul_complet.py` : nombre de questions, opérations au hasard, chrono |
| Pierre, feuille, ciseaux | `pfc_etape1.py` à `pfc_etape3.py` | `pfc_complet.py` : majuscules, raccourcis p/f/c, saisie redemandée, statistiques |

Ces corrigés n'utilisent que ce qui était vu au moment du TP : variables, `input`, conditions, boucles. Si vous tapez des lettres là où un nombre est attendu, le programme s'arrête avec une `ValueError` : on a vu jeudi comment l'éviter avec `try` / `except`.
