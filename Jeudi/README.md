# Jeudi : dictionnaires, modules, fichiers, erreurs

Les corrigés commentés des exercices du jeudi. Lancez-les depuis ce dossier : les fichiers de données `eleves.txt`, `texte.txt` et `questions.txt` doivent être à côté des programmes.

| Fichier | Exercice |
|---|---|
| `j1_lettres.py` | J1. Compter les lettres avec un dictionnaire |
| `j2_repertoire.py` | J2. Le répertoire téléphonique, avec un menu |
| `j3_traducteur.py` | J3. Le petit traducteur mot à mot |
| `j4_juste_prix.py` | J4. Le juste prix, avec une saisie qui ne plante jamais |
| `j5_carnet.py` | J5. Le carnet de notes, lu dans `eleves.txt` |
| `j6_frequents.py` | J6. Les mots les plus fréquents de `texte.txt` |
| `j7_quiz.py` | J7. Le quiz, lu dans `questions.txt`, scores dans `scores.txt` |
| `j8_wc.py` | J8. La commande `wc` en Python : `python3 j8_wc.py texte.txt` |

Le dossier `fichiers/` contient les corrigés des exercices « Explorer ses fichiers avec Python ».
