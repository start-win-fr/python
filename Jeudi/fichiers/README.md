# Explorer ses fichiers avec Python : corrigés

Avant tout, fabriquez le dossier de test, une seule fois :

```bash
python3 creer_bac_a_sable.py
```

Puis lancez chaque corrigé depuis ce dossier, à côté de `bac-a-sable`.

| Fichier | Exercice |
|---|---|
| `f1_lister.py` | F1. Lister un dossier |
| `f2_type.py` | F2. Fichier ou dossier ? |
| `f3_tailles.py` | F3. La taille de chaque fichier |
| `f4_lisible.py` | F4. Des tailles lisibles (o, Ko, Mo, Go) |
| `f5_total.py` | F5. Le total et le plus gros fichier |
| `f6_extensions.py` | F6. Trier par extension |
| `f7_trier.py` | F7. Du plus gros au plus petit |
| `f8_arbre.py` | F8. Descendre dans les sous-dossiers avec `os.walk` |
| `f9_recents.py` | F9. Les fichiers modifiés depuis le 1er octobre 2026 |
| `f10_vides.py` | F10. Les fichiers et dossiers vides |
| `f11_mon_ls.py` | F11. Votre propre `ls -l` : `python3 f11_mon_ls.py bac-a-sable/documents` |
| `f12_disque.py` | F12. L'espace disque |
