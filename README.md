# Prepavenir
![CI](https://github.com/start-win-fr/python/actions/workflows/ci.yml/badge.svg)

Projet Python du dépôt Prepavenir.

## Prérequis

- Python 3 installé

## Installation

Clonez le dépôt, puis placez-vous dans son dossier. Si le projet fournit un fichier `requirements.txt`, installez ses dépendances avec :

```bash
python -m pip install -r requirements.txt
```

## Utilisation

Exécutez le script Python correspondant à ce que vous souhaitez lancer :

```bash
python chemin/vers/script.py
```

## Structure du dépôt

Les scripts et ressources du projet se trouvent dans ce dépôt. Consultez les fichiers Python pour découvrir les fonctionnalités disponibles.
